# 🛒বাজার দর — BazarDor

BazarDor is a responsive website for checking daily market prices of essential products in Bangladesh. Users can compare price changes, browse categories, and explore prices across different markets.

## Technologies Used

- Next.js
- React
- TypeScript
- Tailwind CSS
- Better Auth
- MongoDB Atlas
- React Fast Marquee
- React Hot Toast
- Vercel

## Features

- **Daily Product Prices:** View current prices, product emojis, and units from the API.
- **Scrolling Price Ticker:** Follow product prices through a continuously scrolling marquee.
- **Price Changes:** Discover the top six products with the largest price increases and decreases.
- **Category Browsing:** Browse products by category with active navigation highlighting.
- **Price Sorting:** Sort category products by price in ascending or descending order.
- **Product Details:** View historical prices, market prices, and minimum, maximum, and average prices.
- **Authentication:** Register and sign in using email/password, Google, or GitHub.
- **Protected Routes:** Require login to access product details and profile pages.
- **Profile Management:** View account information and update your name.
- **Responsive Design:** Browse comfortably on mobile, tablet, and desktop.
- **Bangla Formatting:** Display Bangla prices and the current date in Bangladesh time.
- **Loading and Error States:** Show loading skeletons, toast notifications, and a friendly 404 page.
